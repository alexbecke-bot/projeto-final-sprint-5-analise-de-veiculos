Dashboard de Análise de Veículos

Sobre o projeto

Este projeto tem como objetivo analisar dados de anúncios de veículos usados, explorando informações como quilometragem e preço dos veículos.

A aplicação permite visualizar os dados por meio de gráficos interativos, facilitando a identificação de padrões e a interpretação das informações.

Funcionalidades

* Visualização da distribuição da quilometragem dos veículos por meio de um histograma.
* Gráfico de dispersão para analisar a relação entre quilometragem e preço.
* Exibição da tabela de dados utilizada na análise.

Tecnologias utilizadas

* Python
* Pandas
* Streamlit
* Plotly
* Jupyter Notebook

Estrutura do projeto

* EDA.ipynb: análise exploratória dos dados.
* app.py: aplicação interativa desenvolvida com Streamlit.
* vehicles_us.csv: base de dados utilizada.
* requirements.txt: dependências necessárias para executar o projeto.

Aplicação online

Acesse o dashboard:

https://projeto-final-sprint-5-analise-de.onrender.com/

Como executar localmente

1. Clone este repositório.
2. Instale as dependências:
    pip install -r requirements.txt
3. Execute a aplicação:
    streamlit run app.py
